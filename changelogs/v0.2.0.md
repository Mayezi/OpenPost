# v0.2.0 (2026-11-06)

## 新功能
- 引入 Rust 原生桌面运行时，将前端构建产物内嵌打包为轻量、零外部依赖的本地二进制程序
- 新增全平台官方应用图标资源包（Windows / macOS / Linux / Android）与页面元信息配置
- 新增覆盖 Windows、macOS、Linux 三端的 GitHub Actions 自动化构建与发布流水线

## 改进
- 完善 README 文档，补充本地优先架构说明、核心能力介绍与官方品牌图标展示
- 统一 CI/CD 与工程环境至 Node.js 22 与 `ubuntu-24.04`，拆分前端与 Rust 构建阶段以提升缓存效率
- 精简冗余依赖与构建脚本，规范三端原生安装包产出命名并更新 GitHub Actions 依赖版本

## 问题修复
- 移除仓库中易引发冲突的锁文件并补充本地数据目录忽略规则，提升跨平台构建稳定性
