# v0.3.0 (2026-11-06)

## 新功能
- 迁移至 `tao` 与 `wry` 原生 WebView 桌面窗口框架，提供更稳定的原生跨平台运行体验
- 新增桌面端原生窗口拖拽能力（通过 Rust 后端接口触发系统级窗口拖动）
- 实现本地磁盘工作区数据自动恢复（Hydration），新增请求保存状态标识与多标签页激活校验
- 新增平面键值对 JSON Header 解析工具，支持更灵活的请求头处理

## 改进
- 将 Windows 安装产物重构为标准 NSIS 安装向导并配置官方 Windows 应用图标，移除冗余便携版构建
- 更新内置默认 HTTP 调试集合、环境变量预设及本地服务文件状态上报逻辑

## 问题修复
- 配置 Windows 子系统属性，修复桌面应用启动时附带弹出黑色控制台窗口的问题
- 显式链接 Windows 必需系统库，修复 Windows 平台编译链接依赖缺失错误
