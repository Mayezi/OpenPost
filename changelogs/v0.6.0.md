# v0.6.0 (2026-11-22)

## 新功能
- 新增基于 GitHub Releases（`Mayezi/OpenPost`）的完整检查更新功能，支持启动自动检查、版本比对弹窗、更新说明展示及多平台安装包直链下载
- 新增独立版本更新日志存储目录（`changelogs/`），严格按「新功能 / 改进 / 问题修复」三大主题结构化归档每个版本变更
- 设置中心新增「软件更新」面板，支持启动自动检查开关、预发布版本订阅以及历史版本日志查阅

## 改进
- 调整 GitHub Actions 自动打包策略为仅由 `v*` Tag 触发，发版时自动读取对应版本的 `changelogs/<tag>.md` 作为 Release 说明并同步注入三端安装包版本号
- 移除侧边栏文件夹双击触发重命名交互，防止误触并简化操作体验
- 统一更新界面排版为系统原生字体，去除主题数量角标与图标背景色，并固定更新源无需用户手动配置
- 更新检查请求自动复用已配置的网络代理，提升不同网络环境下的连通稳定性

## 问题修复
- 修复多平台并行上传 GitHub Release 产物时偶发创建竞态的问题，改为汇总任务统一发布与上传
- 修复按完整 Git 历史重新梳理 0.x 语义化版本号并对齐本地与桌面端默认版本基准
